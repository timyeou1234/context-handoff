## Starter prompts

3. Check context health and hand off only if a fresh thread is warranted.

## Initial release notes

Initial public-directory submission of a skills-only workflow for preserving task continuity across fresh Codex threads. The plugin validates a bounded recovery packet, requires a destination sentinel, fails safely on unsupported surfaces, and offers separately authorized, post-verification source archival. It uses no MCP server, hosted service, authentication, or reviewer credentials.
