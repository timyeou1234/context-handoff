# Support

For bugs, documentation issues, security-conscious behavior reports, or feature requests, open a [GitHub issue](https://github.com/timyeou1234/context-handoff/issues).

Include the plugin version, Codex surface, relevant command output with secrets removed, and whether thread-management APIs were available. Do not post handoff packets that contain private repository information or personal data.

This community project does not provide guaranteed response times or emergency support.
